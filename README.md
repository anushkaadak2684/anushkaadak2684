### 🎓 ClassSphere

**Real-Time Virtual Classroom Platform**

A full-stack virtual classroom platform built around **real-time communication, live collaboration, and student performance management**.

**Highlights:**

* Role-based teacher/student workflows with authentication and authorization
* Real-time communication using **Socket.io**
* Live video, screen sharing and participant controls using **WebRTC**
* Real-time chat, hand raise, mute and session management
* Assignment creation, submissions, coursework and **file uploads**
* Attendance tracking and student performance analytics
* Cloud-based media management using **Cloudinary**
* RESTful backend with **React, Node.js, Express.js and MongoDB**

**Tech:** React • Node.js • Express.js • MongoDB • Socket.io • WebRTC • Firebase • Cloudinary

### 💰 WalletWise

**Java-Based Digital Wallet & Expense Management System**

A Java-based financial management system built with **OOP, SOLID principles, design patterns, and layered architecture**.

**Highlights:**

* Personal and business wallet management
* Expense, transaction, deposit and withdrawal tracking
* Budgets, savings goals, reports and transaction filtering
* **Model–Repository–Service architecture** with separation of concerns
* **OOP principles** using abstraction, inheritance, encapsulation and polymorphism
* **SOLID principles and Repository/Service design patterns**
* MySQL database integration using **JDBC**
* Secure authentication with **BCrypt password hashing**

**Tech:** Java • MySQL • JDBC • Maven • Swing • BCrypt
